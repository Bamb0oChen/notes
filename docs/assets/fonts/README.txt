Self-hosted fonts, downloaded 2026-09-12.

Inter variable (normal):
https://github.com/rsms/inter/blob/master/docs/font-files/InterVariable.woff2
License: Inter-LICENSE.txt

Source Han Sans CN variable (normal, Simplified Chinese):
https://github.com/adobe-fonts/source-han-sans/blob/release/Variable/WOFF2/OTF/Subset/SourceHanSansCN-VF.otf.woff2
License: SourceHanSans-LICENSE.txt
The original font is mechanically split into disjoint Unicode ranges by
maintenance/build_font_subsets.py. All original mapped characters are retained.
source-han-sans.css allows the browser to request only matching ranges.

JetBrains Mono (normal, Regular and Bold):
https://github.com/JetBrains/JetBrainsMono/tree/master/fonts/webfonts
License: JetBrainsMono-LICENSE.txt

All fonts use font-display: swap. System generic fonts are only emergency
fallbacks while loading or for characters outside these fonts' coverage.
