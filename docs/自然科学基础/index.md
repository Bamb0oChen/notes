# 0.前言

我经常在想除了数学的基础知识对我学习cs有什么用，但是我后来发现其实这只是一个伪命题，不是所有东西的存在都有必要（当然这不是春秋笔法说这些知识没用），我想很多时候自然科学基础其实是给我们提供了一个观察世界的方式，我们能够去解释我们的世界

之前有幸和一个同学交谈，他提到自己对课程的看法逐渐发生了改变，认为课程不应该成为我们的目的，课程背后和真实世界的联系才是重要的。具体的就不详述了，但是听完后我也开始反思我在看待这些课程的视角，我之前是不是一直把他们当作一个单纯的成绩工具呢？当我不需要绩点以后，我是不是又把他们当成了一些完全不需要的课程呢？

太多的问题其实需要回答，不过我想现在我能做的就是慢慢去摸索
