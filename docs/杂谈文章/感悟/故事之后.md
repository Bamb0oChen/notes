# 故事之后

倘若有一台机器，它能给你任何你想要的体验，从刻骨铭心的爱恨情仇，到万人敬仰的功成名就，而与此同时，你却不会感受到这些是虚拟的。那么，你愿意一辈子在这个机器里面生活吗？

哲学家诺齐克在《无政府、国家、乌托邦》中提出的“体验机”思想实验，不禁让人反思体验与实际的区别。他给出了人们不愿接入体验机的几种理由：我们做某些事，并不只是为了获得做那些事的感觉；我们希望通过经历成为某种人，而不是一个被动接收体验的容器；而且，真实世界总有超出既有想象的未知。

如此，题干的这种假定似乎就是把很多影视作品纳入了体验机的范畴——我们为了暂时逃离现实世界的骨感和淡漠，转身投向这些影视作品所构建的温柔乡。因为现实中的爱情往往难以避免地夹杂着物质、门第和权衡，所以人们会怀念《情书》中跨越生死和岁月的爱与温存，为了苍茫雪地上的一句“お元気ですか”而落泪；因为人们总觉得善恶美丑在当下的界限逐渐模糊，所以《甄嬛传》中的平反雪耻、王者归来才能够经久不衰。可是，当我们把自己装进他人的皮套中走过一遭后，我们自己到底又剩下什么呢？更进一步，如果我们从开始就知道一切的体验不过是虚拟的故事，我们又将如何面对我们的现实呢？

然而，前面的类比忽略了一点：我们可以从影视作品中随时抽离。这恰恰是影视剧与体验机的关键区别。体验机将人封闭在预设的体验里，而影视作品带来的触动，却有机会延伸到现实中的认识与行动。我曾在B站看过导演小策关于AI冲击创作者的视频，其中谈到，在AI也能生成作品的时代，坚持亲手创作仍然具有意义。创作者把心中的想象一点点变成作品，这个过程本身就是重新认识自己。观众也类似：走出影院，故事或许结束了，但它激起的勇气与问题未必随之消失。

同时，所谓剧本也好，小说也罢，最勾人魂魄的难道不是它带给人的超脱思维定式的体验吗？《五岛医生诊疗所》成为日本家喻户晓的经典作品，因为面对质疑之中仍能悬壶济世，守医者仁心，本来就是一种意料之外，情理之中的设计。再以《情书》为例，藤井树跨越时空的未竟之爱最终竟由一个荒诞的巧合所揭露（我就不剧透了），这种情节本身就是能让人相信所谓“百步之外，仍有爱在”。这种感受同样也使人重新审视我们的世界，我们也终于认识到原来爱能够如此纯粹，原来生命能够有如此激情，原来我们的人生能够有无限的可能。

当然，影视作品本身作为一种传媒介质也展示出了独特的审美趣味，很多时候我们结束电影时留下的往往不是惊心动魄的剧情，而是一种余韵绕梁的美学回味，而这种感受恰恰是题干中所忽视的部分，我们会记得程蝶衣的最后一舞，会记得霍格沃茨的天马行空，也会记得《指环王》中的恢弘壮阔，这些体验之外的事物，我觉得是很难用所谓“温柔”而一言以蔽之的。不仅如此，这种审美趣味同样也包含着国家的基因符号和文化脉络，2019年人们为《流浪地球》而感动，觉得看到了中国科幻的未来，2024年人们为了《黑神话》而激动，看到中国的游戏能和其他国家的作品角逐，2025年人们为了《哪吒2》而兴奋，因为人们见证了中国动画从原创到超越的励志故事，这种埋藏在电影背后的精神和故事，往往让我们的观看体验有了更深的层次

当然，沉浸也可能成为逃避。倘若一个人不断用下一集覆盖眼前的问题，只愿意体验别人的成长，却不愿面对自己的选择，那么故事确实会变成温柔的陷阱。但“沉浸”描述的是观看时投入了多少，“逃避”说的却是我们怎样对待现实。二者并不能直接画上等号。不过，判断一次追剧是否值得，或许不在于我们为它流过多少眼泪，而在于合上屏幕后，是否还能带着新的理解继续生活。

回到题干，电影当然不只是所谓“逃离现实的温柔陷阱”。恰恰相反，人们也能通过电影看清现实，再重新走进现实。

我想，纵使叙事温柔，影视作品背后蕴藏的感染力，也能够让人在走出故事之后，仍愿意对现实抱有期待。
