在 Linux 系统中，输入命令 ls -a 的主要作用是什么？
[] 
   
   1. 以长格式显示文件的详细权限和修改时间。
   Incorrect. 以长格式显示详细信息使用的是 -l 参数，而不是 -a。
   2. 列出目录下的所有文件，包括以 . 开头的隐藏文件。
   Correct! -a 代表 all，会显示所有文件，包含默认隐藏的以点开头的文件。
   3. 递归列出当前目录及其所有子目录中的文件。
   Incorrect. 递归列出目录通常使用的是 -R 参数。
   4. 仅显示文件的大小和占用的磁盘空间。
   Incorrect. 查看文件大小时通常会结合 ls -lh 或使用 du 命令。

想一想在 Linux 中，有些文件名称前面带有小数点 . 默认是看不见的，若想把它们全部“显形”该用哪个字母代表的参数？
当你在 /home/user/documents 目录下时，执行命令 cd ..，当前工作目录会变成什么？
[] 
   
   1. /home/user
   Correct! .. 表示上一层目录（父目录），从 /home/user/documents 返回上一层即为 /home/user。
   2. /home
   Incorrect. /home 是上两层的目录，执行 cd ../.. 才会到达这里。
   3. /root
   Incorrect. /root 是超级管理员（root 用户）的家目录，与普通用户的路径无关。
   4. /home/user/documents
   Incorrect. 路径没有发生改变，这是未移动或执行错误时的表现。
   
Hint:
.. 在路径中代表特殊的含义，通常指向上一层目录。
执行命令 cd ~（或者直接输入 cd）会将当前工作目录切换到哪里？
[] 
   
   1. 根目录 /
   Incorrect. 切换到根目录需要使用 cd /。
   2. 上一次访问的目录
   Incorrect. 切换到上一次访问的目录应该使用 cd -。
   3. 当前目录的父目录
   Incorrect. 切换到父目录应该使用 cd ..。
   4. 当前用户的家目录（Home Directory）
   Correct! 符号 ~ 在 Linux 中代表当前登录用户的家目录。
   
Hint:
符号 ~ 在 Linux 中代表当前用户的专属私人地盘（例如 /home/username）。
下列选项中，哪个属于绝对路径的典型特征？
[] 
   
   1. 以当前目录符号 . 开头
   Incorrect. 以 . 开头通常用于表示相对路径中的当前目录。
   2. 以父目录符号 .. 开头
   Incorrect. 以 .. 开头属于相对路径的一种用法。
   3. 从根目录 / 开始写起
   Correct! 绝对路径必须从根目录 / 这一最顶层开始，不论当前你在哪个位置。
   4. 仅包含文件名，不包含任何斜杠
   Incorrect. 仅包含文件名通常是在当前目录下直接引用该文件或目录。
   
Hint:
绝对路径和相对路径的最大区别在于起始参考点不同，一个是至高无上的根，另一个是当前所在的位置。
假设你当前在 /var 目录下，若想通过相对路径进入下级名为 log 的子目录，应该使用哪个命令？
[] 
   
   1. cd log
   Correct! 在当前目录下直接输入子目录名 log 就是最典型的相对路径写法。
   2. cd /log
   Incorrect. cd /log 是绝对路径，它会去寻找根目录下的 log 文件夹，而不是 /var/log。
   3. cd ~log
   Incorrect. ~log 不是标准的路径切换语法。
   4. cd ..log
   Incorrect. ..log 拼写错误，无法正确导航。
   
Hint:
相对路径不需要从根目录 / 开始，如果目标就在你面前的当前目录里，直接写名字即可。

下面是我的原文笔记，对linux等计算机工具语法感兴趣的可以去看mit的missing semester

* **参数与通配符**：通过 `flag` 调节行为，通过 `globbing`（如 `*`, `{}`）高效批量操作。
* **流与重定向**：利用 `stdin` / `stdout` / `stderr` 和管道 `|` 实现数据流转，使用 `>` / `<` 等符号控制数据去向。
* **环境变量**：用于子进程通信与配置传递（`export`）。
* **返回码**：Shell 通过返回码（0 为成功，非 0 为失败）进行逻辑判断（`&&` / `||`）。
* **信号与控制**：通过信号（如 `SIGINT`）管理进程生命周期。
