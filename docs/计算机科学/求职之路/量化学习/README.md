## 每项完成标准

1. 先读题目、规则和环境要求，自己尝试实现。
2. 卡住后补对应课程；不要因一个卡点重刷整门课。
3. 通过可用测试，能独立解释核心代码、边界条件和一个失败案例。
4. 留下环境、运行命令、结果与个人贡献。在线评分不开放时，不宣称获得官方分数。
5. AI 用于概念解释和调试反馈，遵守课程规则；不把生成的完整解答当作个人掌握。
