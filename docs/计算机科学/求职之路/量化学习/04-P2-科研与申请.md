# P2：科研与申请

可以与学习并行，不必等所有 Lab 做完。当前优先使用已有 HPC / 模型量化项目。

## 科研项目待办

- [ ] 选一个能解释主要实现、能重复运行的项目。
- [ ] 明确一个研究问题与评价指标。
- [ ] 固定代码、环境、输入、配置，复现基线。
- [ ] 阅读一篇与问题直接相关的论文或技术报告，记录方法、假设、证据与局限。
- [ ] 提出一项改动，先验证正确性。
- [ ] 做公平对照、重复测量、消融与不同输入测试。
- [ ] 记录失败结果，说明适用范围。
- [ ] 整理源码、README、结果表和简短报告。

## 申请待办

- [ ] 简历区分实际完成、协作完成与尚在学习的能力。
- [ ] 准备五分钟项目讲解：问题、方法、个人贡献、证据、失败与下一步。
- [ ] 按具体岗位核对学历、年级、方向、出勤和地点。
- [ ] 符合条件时开始申请，将反馈用于调整学习重点。
