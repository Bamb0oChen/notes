## 学习路线

**技术线**：Data / Bomb → 缓存与 Cache Lab → 深度学习框架 → GPU 与系统优化 → 科研交付。

**量化线**：金融理论 → 组合优化 → 模型评估 → 市场模拟 → 指标与策略 → 样本外研究报告。

两条线的进度独立，不需要全部学完才参与科研或申请实习。CMU HW0 可以提前尝试，发现基础缺口再补。

!!! tip "怎样算完成"
    能运行、检查结果、独立解释、留下复现记录。先做 Lab，卡住补对应知识。通过本地测试不等于获得官方评分。


## CSAPP 基础与 Lab


你尚未学完 CSAPP，因此采用“Lab → 卡点 → 对应章节 → 验证”的方式。无需等课程看完，也不直接跳过基础。

[官方 Lab 与 Self-Study Handout](https://csapp.cs.cmu.edu/3e/labs.html)

### 第一批：立即开始

- [ ] 准备 Linux／WSL 环境，确认编译器、调试器与作业测试工具能运行。
- [ ] **Data Lab**：按需补教材第 2 章，理解位操作、补码、移位与浮点表示；同时检查操作限制与正确性。
- [ ] **Bomb Lab**：按需补第 3 章，练习 GDB、反汇编、寄存器、栈、循环与函数调用；写推导过程，不只记录答案。

### 第二批：对接 HPC / MLSys

- [ ] 第 6 章：内存层次、缓存与局部性。
- [ ] **Cache Lab Part A**：实现缓存模拟器，验证命中、未命中和替换计数。
- [ ] **Cache Lab Part B**：优化矩阵转置，解释缓存未命中变化。此处模拟器指标不等于实际端到端运行速度。

### 第三批：补 OS 基础

- [ ] 第 8 章：进程、异常控制流、信号。
- [ ] **Shell Lab**：实现任务控制，检查前后台任务与信号处理。
- [ ] 第 9 章：虚拟内存与动态内存分配。
- [ ] **Malloc Lab**：实现分配器，比较正确性、利用率与吞吐。

### 后续选做

- [ ] **Attack Lab**：深化栈和机器级程序理解。
- [ ] **Architecture Lab**：深化流水线与软硬件协同。
- [ ] **Proxy Lab**：在学完相关网络、I/O 与并发知识后实现代理。

选做表示当前申请目标下优先级较低，不表示这些内容可以永久省略。不同 handout 环境较旧，先读 README；平台不兼容时先解决环境，不抄解答绕过。


## 量化与金融


与 CSAPP 并行，先建立数据、风险和验证意识。以下是官方课程作业；完成不意味着策略可用于实盘。

### 金融理论：按项目需要学习

[MIT 15.401 Finance Theory I](https://ocw.mit.edu/courses/15-401-finance-theory-i-fall-2008/) · [习题](https://ocw.mit.edu/courses/15-401-finance-theory-i-fall-2008/pages/problem-sets/)

- [ ] Risk and Return、Portfolio Theory：配合 P2。
- [ ] Equities、Efficient Markets：配合 P6 / P8。
- [ ] CAPM and APT：理解基准与风险暴露。
- [ ] 后续选学 Fixed Income、Futures、Options。

MIT 课程为 2008 年版本，基础理论可用，市场制度与案例需更新。

### CS7646：按依赖完成项目

[课程入口](https://lucylabs.gatech.edu/ml4t/)。下面统一使用 Fall 2023，避免混用模板。

- [ ] [P2：Optimize Something](https://lucylabs.gatech.edu/ml4t/fall2023/project-2/)：组合权重优化，理解收益、风险与目标函数。
- [ ] [P3：Assess Learners](https://lucylabs.gatech.edu/ml4t/fall2023/project-3/)：学习器实现、过拟合与模型比较。
- [ ] [P5：Marketsim](https://lucylabs.gatech.edu/ml4t/fall2023/project-5/)：现金、持仓、订单、手续费与冲击成本。
- [ ] [P6：Indicator Evaluation](https://lucylabs.gatech.edu/ml4t/fall2023/project-6/)：指标实现与评估，为策略提供输入。
- [ ] [P7：Q-Learning Robot](https://lucylabs.gatech.edu/ml4t/fall2023/project-7/)：状态、动作、奖励与 Q-learning。
- [ ] [P8：Strategy Evaluation](https://lucylabs.gatech.edu/ml4t/fall2023/project-8/)：手工策略与学习策略、样本内外和成本实验。

这些是优先选做项目，不是完整课程全部作业。部分模板、数据与评分需要课程权限；先检查访问条件，自学可做本地验证。

### 研究交付：自拟扩展

- [ ] 保存数据来源、调整方式、时间范围和缺失值处理。
- [ ] 检查未来信息、训练测试时间划分与信号执行时点。
- [ ] 对比基准、换手、毛收益与成本后收益。
- [ ] 检查参数与时期敏感性，保留失效案例。
- [ ] 输出可复现 notebook 和研究报告。

### 公司与投资分析：副线

- [ ] [耶鲁 Financial Markets](https://oyc.yale.edu/economics/econ-252)：选学风险、分散化、股票、行为金融和金融机构。
- [ ] [沃顿财务会计](https://www.coursera.org/learn/wharton-accounting)：三张报表；结合一家公司的官方年报。
- [ ] [Damodaran 公司金融](https://pages.stern.nyu.edu/adamodar/New_Home_Page/webcastcfonline.htm)：投资、融资、资本成本。
- [ ] [Damodaran 估值](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/webcastvalonline.htm)：在会计与公司金融基础后学习。

副线一次只开一门。Coursera 完整内容与证书权限以注册页面为准。


## MLSys


CSAPP 尚未完成不妨碍尝试 HW0，但课程要求的 Python、C++、线性代数、微积分、概率与机器学习基础需要逐项补齐。

### CMU：先理解深度学习框架

[课程官网](https://dlsyscourse.org/) · [官方 GitHub](https://github.com/dlsyscourse)

- [ ] [HW0](https://github.com/dlsyscourse/hw0)：独立完成基础诊断、Softmax 与梯度实现；遇到知识缺口先补。
- [ ] [HW1](https://github.com/dlsyscourse/hw1)：计算图、自动微分、梯度验证。
- [ ] [HW2](https://github.com/dlsyscourse/hw2)：网络模块、优化器、训练流程。
- [ ] **HW3**：NDArray、CPU / CUDA 后端；先补缓存、数据布局和 GPU 并行基础。
- [ ] **HW4（后续）**：卷积、RNN 等模型实现。

官网目前为 2026 版，录像含 2022 版。HW3 / HW4 的可访问官方材料入口尚未确认，开始前从对应版本课程获取，不使用猜测链接。

### Stanford CS336：模型与系统优化

[Spring 2025 课程、讲义与视频](https://cs336.stanford.edu/spring2025/)

- [ ] [A1 Basics](https://github.com/stanford-cs336/assignment1-basics)：tokenizer、Transformer、优化器与小型训练基线。
- [ ] [A2 Systems](https://github.com/stanford-cs336/assignment2-systems)：benchmark、profiling、注意力优化和并行训练实验。

跟随 2025 课程时选择对应 `spring2025` 分支。先确认 GPU / 多卡需求；只有 CPU 时先完成支持的部分，未运行的实验明确标记。

### 推进标准

- [ ] 独立解释前向、反向、参数更新与训练 / 评估区别。
- [ ] 用测试验证算子与梯度。
- [ ] 建立测量基线，固定输入、精度、环境，处理 GPU 同步和预热。
- [ ] 用证据判断计算、访存或调度瓶颈。
- [ ] 任何优化同时检查正确性、性能、显存与数值变化。


## 科研与申请


可以与学习并行，不必等所有 Lab 做完。当前优先使用已有 HPC / 模型量化项目。

### 科研项目待办

- [ ] 选一个能解释主要实现、能重复运行的项目。
- [ ] 明确一个研究问题与评价指标。
- [ ] 固定代码、环境、输入、配置，复现基线。
- [ ] 阅读一篇与问题直接相关的论文或技术报告，记录方法、假设、证据与局限。
- [ ] 提出一项改动，先验证正确性。
- [ ] 做公平对照、重复测量、消融与不同输入测试。
- [ ] 记录失败结果，说明适用范围。
- [ ] 整理源码、README、结果表和简短报告。

### 申请待办

- [ ] 简历区分实际完成、协作完成与尚在学习的能力。
- [ ] 准备五分钟项目讲解：问题、方法、个人贡献、证据、失败与下一步。
- [ ] 按具体岗位核对学历、年级、方向、出勤和地点。
- [ ] 符合条件时开始申请，将反馈用于调整学习重点。
