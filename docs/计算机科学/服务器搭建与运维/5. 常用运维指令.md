| 功能             | 命令                         | 作用              | 示例                                                                 |
| -------------- | -------------------------- | --------------- | ------------------------------------------------------------------ |
| 查看本机 IP        | `ip addr`                  | 查看所有网卡信息        | `ip addr show eth0`                                                |
| 查看本机 IP（简洁）    | `hostname -I`              | 仅显示 IP 地址       | `hostname -I`                                                      |
| 查看默认网关         | `ip route`                 | 查看路由表           | `ip route`                                                         |
| 查看默认路由         | `ip route \| grep default` | 查看默认网关          | `default via 192.168.1.1`                                          |
| 查看 ARP(IP→MAC) | `ip neigh`                 | 查看邻居缓存          | `ip neigh`                                                         |
| 查看 ARP(旧命令)    | `arp -a`                   | 查看 IP-MAC 映射    | `arp -a`                                                           |
| 添加静态 ARP       | `ip neigh add`             | 添加 IP-MAC 映射    | `sudo ip neigh add 192.168.1.10 lladdr aa:bb:cc:dd:ee:ff dev eth0` |
| 删除 ARP         | `ip neigh del`             | 删除映射            | `sudo ip neigh del 192.168.1.10 dev eth0`                          |
| 清空 ARP 缓存      | `ip neigh flush all`       | 清除邻居缓存          | `sudo ip neigh flush all`                                          |
| DNS 查询         | `dig`                      | 域名→IP           | `dig www.baidu.com`                                                |
| DNS 查询         | `nslookup`                 | 域名解析            | `nslookup www.baidu.com`                                           |
| DNS 查询         | `host`                     | 简洁查询            | `host www.baidu.com`                                               |
| 查看 hosts 映射    | `cat /etc/hosts`           | 本地域名映射          | `cat /etc/hosts`                                                   |
| 编辑 hosts       | `vim /etc/hosts`           | 修改域名映射          | `sudo vim /etc/hosts`                                              |
| 查看监听端口         | `ss -tulnp`                | 查看所有监听端口        | `ss -tulnp`                                                        |
| 查看指定端口         | `ss -lntp \| grep 8080`    | 查看端口占用          | `ss -lntp \| grep 80`                                              |
| 查看连接           | `ss -ant`                  | 查看 TCP 连接       | `ss -ant`                                                          |
| 查看所有连接         | `netstat -tunlp`           | 老命令             | `netstat -tunlp`                                                   |
| 查看 NAT 规则      | `iptables -t nat -L -n -v` | 查看端口映射          | `iptables -t nat -L -n -v`                                         |
| 查看 nftables    | `nft list ruleset`         | 新版 NAT 规则       | `sudo nft list ruleset`                                            |
| 查看防火墙          | `firewall-cmd --list-all`  | Firewalld 配置    | `firewall-cmd --list-all`                                          |
| 查看网卡           | `ip link`                  | 查看网络接口          | `ip link`                                                          |
| 查看 MAC 地址      | `ip link show`             | 查看网卡 MAC        | `ip link show eth0`                                                |
| Ping 测试        | `ping`                     | 测试网络连通性         | `ping 8.8.8.8`                                                     |
| 路由追踪           | `traceroute`               | 查看经过哪些路由        | `traceroute www.baidu.com`                                         |
| MTR 检测         | `mtr`                      | Ping+Traceroute | `mtr 8.8.8.8`                                                      |
| 查看公网 IP        | `curl ifconfig.me`         | 查看公网出口 IP       | `curl ifconfig.me`                                                 |

| 查看容器详细映射 | `docker inspect <container>`                                     |

| 查看网络详情   | `docker network inspect bridge`                                  |
