## 一、知识定位

本章解决的是「服务器从哪里来」的问题。硬件是所有上层服务（操作系统、网络、应用）的物理载体。理解硬件选型，本质上是理解「计算、存储、通信」三大资源如何在物理层面被组合、被限制、被扩展。

---

## 二、核心知识框架

```
服务器硬件搭建
├── 计算子系统（CPU + 主板 + 内存）
│   ├── CPU选型：微架构、插槽、核心数、功耗
│   ├── 主板选型：尺寸规格、芯片组、扩展插槽
│   └── 内存选型：类型、通道、容量、时序
│
├── 存储子系统（系统盘 + 数据盘）
│   ├── SSD：用于系统/缓存，追求IOPS
│   ├── HDD：用于数据/归档，追求容量
│   └── 接口总线：SATA、PCIe通道分配
│
├── 电源子系统（供电与安全）
│   ├── 功率计算：CPU+板卡+硬盘的峰值与稳态功耗
│   ├── 电压稳定性：单路12V vs 多路12V，硬盘损坏的主因
│   └── 接口兼容性：主供电24pin、CPU供电4/8pin、显卡供电6/8pin
│
└── 机箱子系统（物理承载）
    ├── 主板兼容性：ATX/M-ATX/ITX
    ├── 硬盘扩展：盘位数、热插拔背板、散热风道
    └── 散热设计：风道走向、正压/负压、尘滤
```

## 三、逐层展开

### 3.1 计算子系统

#### 3.1.1 CPU

CPU 是服务器的「大脑」，决定了计算能力的上限。在服务器语境下，CPU的关注点与台式机不同：稳定 > 单核性能 > 多核性能 > 功耗。

**选型的关键参数**：

| 参数 | 含义 | 为什么重要 |
|------|------|-----------|
| **微架构** | CPU的设计世代（如 Sandy Bridge、Ivy Bridge） | 同频性能差一个代际约 10-15%，决定了能装什么操作系统版本 |
| **插槽类型** | CPU的物理引脚规格（如 LGA1155、LGA2011） | 决定了主板的唯一选择，错一个数字就装不上 |
| **核心/线程** | 物理核心数 vs 超线程虚拟核心 | OA+轻量Docker：4核8线程够了；AI/虚拟化：需要更多核心 |
| **基础/睿频频率** | 基准频率和单核可以跑的峰值频率 | 睿频决定了突发负载的响应速度，E3-1230 v2：3.3/3.7GHz |
| **功耗 TDP** | 热设计功耗，不是实际功耗但接近满载功耗 | 决定了散热器选择和电源余量，69W~120W 区间适合家用 |
| **ECC支持** | 是否支持内存纠错 | 对数据安全性要求高时需要，E3系列支持，i7不支持 |

**供应链知识**：CPU 二手市场价格与当前发行年份的 CPU 性能直接挂钩。LGA1155 平台（2012年）的 E3-1230 v2 在 2026年的二手价约 100-150元，本质是「性能不算落伍但平台已停产」的折价。价格曲线：新品 2000元 → 退役期 500元 → 垃圾期 150元 → 收藏期 回弹。2026年 LGA1155 处于「垃圾期」末期。

**选型决策树**：
```
需求是纯文件存储 + 基础 Docker？
    └─ 是 → E3-1220 v2（4核4线程，约20元）
需求是 OA + 10+容器 + 偶尔转码？
    └─ 是 → E3-1230 v2（4核8线程，约120元）
需求是 AI 推理 + 多虚拟机 + 软件转码？
    └─ 是 → 换 X99 平台 + E5-2680 v4（14核28线程）
```

#### 3.1.2 主板

主板是「总线」，它的作用是连接 CPU、内存、硬盘、网卡、显卡，让数据能流通。主板的选型决定了整机的扩展天花板。

**关键规格解读**：

| 规格 | 含义 | 实际意义 |
|------|------|----------|
| **尺寸规格** | ATX（30.5cm）、M-ATX（24.4cm）、ITX（17cm） | 决定了机箱选择，也决定了物理插槽数量 |
| **芯片组** | B75、Z77、H61、X99、B660 等 | 决定了 CPU 兼容性、PCIe 通道数、SATA 口数、是否支持超频 |
| **CPU 插槽** | LGA1155、LGA1151、LGA2011 等 | 决定了和 CPU 的唯一配对关系 |
| **内存插槽数** | 2条或4条 | 决定了最大内存容量和双通道能否实现 |
| **SATA 接口** | 2.0 vs 3.0；数量 4/6/8 个 | 决定了能挂多少块硬盘，SATA3.0（6Gb/s）给SSD，2.0给HDD足够 |
| **PCIe 插槽** | x16、x8、x4、x1 的数量和版本 | 决定了能插多少张扩展卡（显卡、网卡、阵列卡） |

**B75 芯片组在 2026 年的地位**：2012年英特尔发布的消费级芯片组。在当年是入门级，在2026年是「NAS 垃圾佬」的宝藏芯片组。核心价值：原生支持 1个 SATA 3.0（6Gb/s）和 4个 SATA 2.0（3Gb/s），华擎 B75 Pro3 通过第三方芯片扩展到 3个 3.0 + 5个 2.0，共 8个 SATA 口——这恰好是 NAS 最需要的规格，而同时代的 H61 只有 4个 SATA 口。

**PCIe 通道分配原理**：CPU 提供 16 条 PCIe 3.0 通道，PCH 芯片组提供额外的 PCIe 2.0 通道。第一条 x16 插槽直连 CPU（显卡用），其余扩展槽走 PCH。这意味着：显卡插在第一条槽走 3.0 x16 全速，网卡/阵列卡插后面的槽走 PCH 的 2.0 x1/x4，速度受限但对 NAS 足够。

#### 3.1.3 内存

内存是「临时工作空间」，CPU 把需要处理的数据从硬盘搬运到内存。内存的速度和容量决定了系统能同时处理多少任务。

**普通台式机内存 vs 服务器内存**：

| 类型 | 特点 | 兼容性 | 适用场景 |
|------|------|--------|----------|
| **普通内存 (Non-ECC Unbuffered)** | 容量 2G-16G/条，1.5V/1.35V | 家用主板通用 | 台式机、普通 NAS、开发机 |
| **ECC 内存 (Non-ECC Unbuffered + ECC)** | 多一颗校验颗粒，纯 ECC 无缓冲 | 需要 CPU+主板同时支持，E3-1230 v2 支持，B75 不支持 | 数据安全性要求高的工作站 |
| **REG ECC (Registered ECC)** | 带寄存器缓冲，支持超大容量 | 仅 X99/C612 等服务器芯片组 | Xeon E5 服务器，B75 插上直接点不亮 |

**通道与容量规划**：
- 双通道：两条内存交替访问，带宽翻倍（64bit → 128bit）。8G×2 的性能优于单条 16G。
- 插槽利用率：4 个槽的主板，优先插 2 条（8G×2），留 2 条升级空间。插满 4 条会增加内存控制器负担，不稳定的概率上升。

**DDR3 2026年行情**：DDR3 已停产，二手市场 8G 单条约 50-70元，16G 单条约 130-150 元且难买。8G×2 16G 是 LGA1155 平台性价比最高的方案。

### 3.2 存储子系统

#### 3.2.1 两种存储介质：SSD vs HDD

| 维度 | SSD | HDD |
|------|-----|-----|
| **原理** | 电子存储，无机械部件 | 磁头+盘片，电磁读写 |
| **顺序读写** | 500-3500 MB/s | 150-200 MB/s |
| **随机读写 (IOPS)** | 数万到数十万 | 几十到一两百 |
| **单 GB 成本** | 约 0.5-1 元/GB | 约 0.1-0.2 元/GB |
| **噪音/功耗** | 0-5W，完全静音 | 5-10W，读写时有咔嗒声 |
| **寿命** | 有写入寿命限制 | 机械磨损，无写入量上限 |

在服务器中的分工：操作系统和 Docker 容器镜像需要频繁随机读写、快速启动 → **SSD**。照片、电影、备份存档需要大容量、低成本 → **HDD**。

#### 3.2.2 HDD 选型：西数颜色系统的本质

西数的颜色不是营销噱头，而是一套「按应用场景优化的固件 + 硬件」分类体系：

| 颜色 | 定位 | 核心技术 | NAS 适用性 |
|------|------|----------|-----------|
| **红盘** | NAS 专用 | NASware 固件：TLER 限时错误恢复，防止 RAID 掉盘 | ✅ 首选 |
| **红盘 Plus/Pro** | NAS 进阶 | 红盘 + CMR 传统磁记录，比普通红盘的 SMR 更稳 | ✅ 强烈推荐 |
| **蓝盘** | 日常家用 | 普通固件，无 TLER，可能被 RAID 控制器误判为坏盘 | ❌ 不推荐用于 NAS |
| **紫盘** | 监控专用 | AllFrame 技术：跳过错误校验保写入流畅 | ❌ 不适合存重要数据 |
| **黑盘** | 高性能 | 性能强，功耗噪音大 | ❌ NAS 上浪费 |
| **金盘** | 企业级 | 最高可靠性，MTBF 250万小时 | ⚠️ 性能溢出，性价比低 |

**核心概念 - CMR vs SMR**：传统磁记录，数据轨道并排写入，修改数据时直接覆盖。优点是随机写入稳定。叠瓦式磁记录，轨道部分重叠，类似屋顶瓦片。修改数据时需重写整块区域，写入大文件时会掉速。结论：NAS 首选 CMR，红盘 Plus 和 Pro 是 CMR，普通红盘可能是 SMR。

**TLER 的含义**：硬盘发现一个扇区读失败时，正常硬盘会反复重试（可能持续 30 秒+）。在 RAID 阵列中，这段时间阵列卡会认为硬盘已掉线。TLER 限制了重试时间（通常 7 秒），超时后向阵列卡报错让阵列卡用冗余数据恢复，而不是把整块硬盘踢出阵列。

#### 3.2.3 SATA 线材

**SATA 线的「方向」背后是机箱布局工程**：L型弯头（90°）用在硬盘端，线从侧面引出不占纵深空间，能贴着机箱侧板走。直头（180°）用在主板端，主板的 SATA 口通常是横排或竖排，直头不会和旁边的接口冲突。

**SATA 2.0 vs 3.0 线材**：物理接口相同，但 SATA 3.0 对线材的屏蔽和串扰要求更高。用 SATA 2.0 线跑 6Gb/s，可能出现误码率升高、CRC 错误（C7 属性报警）、降速重传。结论：机械硬盘（上限 200MB/s）不需要 SATA 3.0 线；SSD 必须用 3.0 线，26AWG 线规是质量好的标志（数字越小越粗）。

**插拔的声音是一种反馈**：SATA 线两端有金属弹片卡扣，插到位会听到清晰的「咔哒」声。这个声音提示弹片已卡入硬盘/主板对应的凹槽。没有听到声音意味着没插紧，震动中可能松动。

### 3.3 电源子系统

#### 3.3.1 功率计算

**峰值 vs 稳态**：硬盘启动瞬间电机启动电流比正常运行时高 2-3 倍。4 块 HDD 同时启动可能瞬间吃掉 100W+，而运行时每块仅 5-8W。电源需要满足峰值功率，而不是只算稳态。

**12V 是关键**：CPU、显卡、硬盘电机都吃 +12V 供电。廉价电源虚标的总功率可能是 3.3V+5V+12V 加起来的「联合功率」，实际 12V 输出能力可能不到总功率的一半。正确做法：不看总功率，只看 +12V 的输出电流（A），乘以 12V 得到有效功率。

**功率需求速算公式**：`(CPU满载功耗 + 显卡满载功耗 + 硬盘数量 × 15W + 50W 余量) × 1.2`。E3-1230 v2（70W） + 无独显 + 4 块硬盘（60W） + 50W 余量 = 180W × 1.2 = 216W。350W 电源已足够。加 GTX 1650 Super（100W）：280W × 1.2 = 336W。450W 稳妥。

#### 3.3.2 电源分类

| 类型 | 特点 | 适用场景 |
|------|------|----------|
| **ATX** | 标准台式机电源，150x86x140mm，丰富的 SATA/大 4pin 线 | 大部分 NAS 机箱，首选 |
| **SFX** | 小型 ATX，125x100x63.5mm，线材少 | ITX 小机箱 |
| **Flex 1U** | 长条型，适合 1U 服务器机箱，风扇噪音大 | 机架式服务器 |
| **DC-ATX 直插** | 无外壳，直接插主板的 24pin 口，需要外接笔记本适配器 | 超小型 DIY NAS |

#### 3.3.3 硬盘杀手：电压不稳

机械硬盘对 +12V 波动极其敏感。规范要求 ±5% 以内（11.4V-12.6V）。劣质电源在负载突增时（如多块硬盘同时启动）电压会瞬间掉到 11V 以下，导致磁头未就位就掉电，轻则出现重映射扇区（05），重则直接敲盘报废。

品牌代工关系：安钛克 HCG 系列由海韵代工，是品质保证；航嘉 WD500K 口碑尚可但品控有波动；安钛克 VP 系列属于入门级，可点亮但不建议用于 7×24 小时 NAS。同样贴「安钛克」牌子，不同系列来自不同代工厂，品质天差地别。电源要看「系列」，不能只看「品牌」。

### 3.4 机箱子系统

#### 3.4.1 主板尺寸与机箱的兼容性

**尺寸的物理含义**：
- **ITX**：17×17cm，1 条 PCIe x16，2 条内存，占用空间最小，扩展性最弱。
- **M-ATX**：24.4×24.4cm，2-4 条 PCIe，4 条内存，紧凑型 NAS 主板的主流规格。
- **ATX**：30.5×24.4cm，5-7 条 PCIe，4 条内存，空间充足，散热好。

**关键概念 - 机箱的「主板支持」是硬约束**：买机箱首先要看支持 ATX 还是仅 M-ATX/ITX。ATX 机箱可以装小板，ITX 机箱绝不能装大板（尺寸超了）。你的华擎 B75 Pro3 是 ATX，选机箱时跳过所有「仅支持 ITX」的选项。

#### 3.4.2 NAS 专用机箱的设计哲学

普通机箱的硬盘位通常是「够用就行」（2-4 个 3.5 寸位）。NAS 专用机箱的核心设计目标是：
- **盘位优先**：4-12 个 3.5 寸热插拔硬盘仓，前置方便更换
- **风道分离**：硬盘仓独立风道，避免 CPU 散热和硬盘散热互相干扰
- **背板设计**：热插拔模组的电路板，集成 SATA 数据和供电，拆装硬盘不需关机
- **电源兼容性**：明确标注支持 ATX/SFX/Flex，避免买了机箱电源装不进去

**热插拔的价值**：服务器/ NAS 需要 7×24 小时运行，更换故障硬盘时不能关机。热插拔背板支持在不关机、不影响服务的情况下抽出旧盘、插入新盘（前提是 RAID 允许降级运行）。对家用 NAS，热插拔是「用了就回不去」的体验：换硬盘不需要关机 → 不需要通知所有用户 → 不需要排队等待启动。

## 四、本章核心概念速查表

| 概念 | 一句话解释 | 实际应用 |
|------|-----------|----------|
| **LGA1155** | Intel 2011-2013 年的 CPU 插槽 | E3-1230 v2、i7-3770 都插这个 |
| **B75 芯片组** | LGA1155 的中端芯片组 | 提供 SATA 3.0、USB 3.0，适合 NAS |
| **PCIe 通道** | CPU/芯片组和扩展卡之间的数据通路 | x16 给显卡，x1/x4 给网卡 |
| **双通道** | 两条内存交替访问，带宽翻倍 | 8G×2 比单条 16G 快 10-20% |
| **ECC 内存** | 能自动纠错的内存 | E3-1230 v2 支持，B75 不支持 |
| **SATA 3.0** | 6Gb/s 接口 | SSD 发挥性能需要这个 |
| **CMR/SMR** | 两种磁记录方式 | CMR 适合 RAID，SMR 写入会掉速 |
| **TLER** | 硬盘限时错误恢复 | 防止 RAID 误判掉盘 |
| **单路 12V** | 电源 12V 输出不分路 | 对多硬盘更友好 |
| **TDP** | 热设计功耗 | 估算散热和电源用，不是实际功耗 |
