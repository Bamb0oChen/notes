# 0. 前言

## 恭喜通过考拉工作室的8.0面试环节

接下来你们要面对的是我们考拉工作室的实践面环节，当然，实践面也可以通过在成果卡上提交重大贡献，获得A等评级，并获得上级批准来免除。

在接下来的几个章节中，我们会从计算机体系开始扫盲，逐步来到开发规范以及我们产品功能的实现，最终，我们会迎来我们的大作业——这部分需要你们组成不多于三人的小队完成。

我们到底想看什么？不是谁能背出更多术语，也不是谁的仓库里有最多文件。我们更想看：你碰到一个需求时，能不能弄明白数据从哪里来，经过了什么，最后为什么变成这个结果。写代码很重要，解释、验证、协作和交接同样重要。

这套题的路线是：

1. [计算机漫游](./1.%20计算机漫游.md)：从一次网页请求出发，把程序、网络和数据串起来。
2. [开发者的基本素养](./2.%20开发者的基本素养.md)：把环境、版本管理、调试、测试和安全习惯补上。
3. [从零到一](./3.%20从零到一.md)：先做一个很小的功能，让请求真的落到数据库里。
4. [大作业](./4.%20大作业.md)：组成最多三人的小队，完成一个可运行、可复现、能讲明白取舍的系统。

没有基础也可以从第一章开始。已经会的内容可以跳读，但最后仍然需要拿出自己的实现和解释。遇到不会的概念，先查、先试、先留下问题；我们更希望看到你把一个不懂的问题逐步弄明白的过程。

## 关于 AI 使用

诚然，当今 AI 基础模型的发展已经达到了一种叹为观止的地步——我们没有必要假装自己不会用它。但 AI 给出的代码能跑，并不代表你理解了它，更不代表它在错误输入、重复请求或多人同时操作时仍然正确。

这版考核允许用 AI 查概念、讨论方案、生成草稿和辅助排错。你需要自己确认它的输出，并且能解释提交的关键代码。答辩时，我们可能从你的实现里挑一条请求，让你说清楚它如何经过接口、业务逻辑和数据库；也可能改一个条件，请你现场判断会发生什么。

请在 README 里简要记录 AI 帮过你什么，以及你如何验证结果。这个记录不是为了抓使用次数，而是为了看你有没有对最终提交负责。不要把密钥、真实用户资料和内部文档直接贴给外部模型。

本章所写的 AI 使用与免考流程是**第一版说明**；若工作室发布更具体的正式规则，以正式规则为准。
