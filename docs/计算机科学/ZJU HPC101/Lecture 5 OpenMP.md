## OpenMP

OpenMP是一个c中的库，我们可以用omp来实现简单的并行

我们来看一个例子

```c
#include <stdio.h>
#include <omp.h> //引入我们的库
int main() {
    printf("Welcome to OpenMP!\n");
    #pragma omp parallel //这个宏定义表示我们要开始了
    {
        int ID = omp_get_thread_num();
        printf("hello(%d)", ID);
        printf("world(%d)\n", ID);  //中间都是并行计算部分
    }
    printf("Bye!");
    return 0;
}
```
