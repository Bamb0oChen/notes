一国的经济主要看三个指标

 1. 产出（GDP）以及增长率
 2. 失业率
 3. 通货膨胀率

通胀的简单理解：低通胀有利于国内经济的坚挺，但不利于出口，高通胀在国内有不稳定性但有利于出口

![](../../images/2026-09-30-12-40-31.png)

同时我们要明确经济波动的危害，当经济走下坡的时候绝对会出现失业，当经济走上坡的时候很大可能会出现通货膨胀

## 日本

![](../../images/2026-09-29-01-08-51.png)

![](../../images/2026-09-29-17-12-55.png)

日本的终生雇佣制使得日本人的失业率很低，这种用工制度让日本人的工作积极性很高，这种积极性在经济上升期百利而无一弊

但是当经济下行的时候，这种制度会发生很大的弊端

1. 裁员的产生导致日本员工几乎找不到下家
2. 为了降本增效不断延长工时

## 宏观经济学史

![](../../images/2026-10-19-23-36-30.png)

首先在古典经济学时期，经济学家们主要做了以下的优化

1. 税收相关的改进
2. 市场经济的研究
3. 货币方法和分工国际化
4. 紧急危机理论

![](../../images/2026-10-19-23-38-20.png)

新时期我们的经济学家又在前人的基础上做了更多的优化

1. 价格水平和积累过程理论
2. 动态均衡理论
3. 经济周期理论
4. 货币数量学说
5. 国民经济统计指标

![](../../images/2026-10-19-23-40-06.png)

当时代接着发展，我们的经济学又获得了提升，我们很多主要的经济模型就是在这个时期出现的（我们很多的知识其实都是这个时候的老东西）

1. IS-LM模型
2. 哈罗德-多玛经济增长模型
3. 乘数-加速数模型
4. 开放条件下的宏观经济模型

![](../../images/2026-10-19-23-43-50.png)

这个时候我们很多的宏观经济学其实已经到达了一个蛮完善的层面

1. 消费函数理论
2. 货币需求理论
3. 经济增长理论
4. 投资理论
5. 通货膨胀理论

当然，我们的挑战同样也是存在的
